Put your logo image in THIS folder, named exactly:

    logo.png

That's it — the app will use it automatically (it replaces the built-in SVG logo).

Notes:
- A square image (e.g. 512 x 512) with a transparent background works best.
- PNG is expected. To use a different format (logo.svg, logo.jpg), open
  src/components/Logo.tsx and change the LOGO_SRC line near the top.
- After adding the file, hard-refresh the browser (Ctrl+F5). If it still doesn't
  show, restart the dev server (npm run dev).

You can delete this README once your logo is in place.

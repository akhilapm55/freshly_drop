Put your Balgin font file in THIS folder, named exactly one of:

    balgin.woff2     (best — smallest, fastest)
    balgin.woff
    balgin.ttf
    balgin.otf

The app uses it automatically for the "Freshly Drop" brand title.
Until a file is here, the title falls back to Poppins.

Tips:
- woff2 is ideal for the web. If you only have a .ttf or .otf, that's fine —
  just drop it in with the name above. (You can convert ttf/otf -> woff2 at
  https://cloudconvert.com/ttf-to-woff2 for faster loading, but it's optional.)
- If you use the bold weight of Balgin, name that file balgin.woff2 — it's the
  one shown for the brand wordmark.
- After adding the file, hard-refresh (Ctrl+F5). If needed, restart: npm run dev

You can delete this README once your font is in place.
